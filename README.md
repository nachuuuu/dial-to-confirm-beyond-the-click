# ☎️ Dial to Confirm

### Beyond the Click — Geek Squad Activities Challenge

## Overview

**Dial to Confirm** reimagines the traditional checkbox as an interactive telephone-inspired confirmation experience.

Instead of simply clicking a checkbox, users interact with a digital dialpad to enter a verification sequence. Once the correct sequence is entered, the confirmation is successfully completed and the underlying checkbox state changes from unchecked to checked.

The goal is to transform a simple, repetitive UI element into something more engaging, interactive, and memorable.

## The Interaction

Traditional interaction:

☐ Click → ☑️ Checked

Dial to Confirm:

Dial a sequence → Receive interactive feedback → Verification → ✓ Confirmed

The interaction combines cursor movement, visual feedback, animations, and telephone-inspired audio to create a more tactile confirmation experience.

## Features

* Interactive telephone-inspired dialpad
* Cursor-based interaction
* Dynamic verification code
* Real-time input feedback
* Telephone-inspired sound effects
* Success and error animations
* Functional checked/unchecked confirmation state
* Reset / Hang Up functionality
* Responsive frontend design

## How It Works

1. A verification sequence is generated.
2. The user interacts with the dialpad to enter the sequence.
3. Each interaction provides visual and audio feedback.
4. The entered sequence is validated.
5. If correct, the confirmation state changes to:

```text
✓ CONFIRMED
```

6. The interaction can be reset using the **Hang Up** button.

## Why This Project?

Checkboxes are one of the most common interactions on the web, but they are almost always static and predictable.

This project explores a simple question:

> What if confirming an action felt like an interaction rather than just a click?

**Dial to Confirm** transforms a traditional checkbox into a small interactive experience inspired by vintage telephone interfaces.
